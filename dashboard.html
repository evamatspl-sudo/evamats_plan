🎯 Czym jest ten dashboard i po co powstał

Dashboard EVAMATS to wewnętrzne narzędzie kontroli sprzedaży i produkcji firmy EVAMATS, stworzone z myślą o właścicielu i kierownictwie. Jego celem jest danie pełnego obrazu wyników biznesowych w jednym miejscu — bez konieczności wchodzenia do Bitrix24, Google Sheets czy raportów BI Builder.

Główna zasada: Dashboard łączy dwa źródła — plan (Google Sheets lub edytor ręczny) z faktem (dane na żywo z Bitrix24 CRM) i pokazuje realizację w czasie rzeczywistym.

Dashboard jest zaprojektowany do pracy przez minimum 20 lat — plan można wpisywać ręcznie dla dowolnego roku, a dane z Bitrix24 będą się aktualizować automatycznie dopóki system CRM działa.

🌐 Jak uzyskać dostęp do dashboardu

Wersja online (zalecana): Dashboard jest hostowany na GitHub Pages — wystarczy otworzyć link w przeglądarce. Działa na każdym urządzeniu (komputer, telefon, tablet) bez żadnego konta, logowania ani instalacji. GitHub Pages to darmowy hosting od Microsoft/GitHub.
Dashboard jest już wdrożony i dostępny pod adresem:
https://evamatspl-sudo.github.io/evamats_plan/
Repozytorium: github.com/evamatspl-sudo/evamats_plan | Konto: evamatspl-sudo

Jak zaktualizować dashboard po zmianach:

  1. Wejdź na github.com/evamatspl-sudo/evamats_plan
  2. Kliknij plik index.html → ikonę ołówka ✏️
  3. Zaznacz całą zawartość (Ctrl+A / Cmd+A) → wklej nową zawartość pliku
  4. Kliknij „Commit changes" → strona zaktualizuje się w ciągu ~1 minuty
Kto może otworzyć link? Absolutnie każdy — bez konta GitHub, bez logowania. Wystarczy link. Możesz go wysłać przez WhatsApp, e-mail, dodać do zakładek — i zawsze działa.

Wersja lokalna (tylko do testów i edycji):

  1. Otwórz Terminal: cd ~/Desktop/AI\ Vibe\ codding && python3 -m http.server 8765
  2. Otwórz: http://localhost:8765/dashboard.html
⚠️ Wersja lokalna działa tylko gdy Terminal jest otwarty i tylko na tym jednym komputerze. Używaj jej tylko do wprowadzania zmian przed wgraniem na GitHub.

📋 Jak korzystać z Edytora planu

  1. Przejdź do zakładki 📋 Edytor planu
  2. Wybierz rok strzałkami ← →
  3. Wpisz wartości planowe dla każdego miesiąca (szt. lub zł)
  4. Kliknij 💾 Zapisz — dane zapisują się w przeglądarce i od razu aktualizują zakładkę Przegląd
  5. Kliknij 📥 Eksportuj aby pobrać kopię JSON na dysk
⚠️ Plan z Edytora ma priorytet nad Google Sheets. Jeśli wpiszesz wartości tutaj — Sheets jest ignorowany dla tego miesiąca.

💾 Backup i przeniesienie na nowy komputer

  1. W zakładce 📋 Edytor planu kliknij 📥 Eksportuj
  2. Pobierze się plik evamats_plan_YYYY-MM-DD.json
  3. Zapisz go w chmurze (Google Drive, iCloud)
  4. Na nowym komputerze: otwórz dashboard → Edytor planu → 📤 Importuj → wybierz plik JSON
Zalecenie: Rób eksport raz w miesiącu przy ustalaniu planu na kolejny miesiąc.
